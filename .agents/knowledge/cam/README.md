# CAM Knowledge

Accepted reusable knowledge for CAM and AscendC operator work:

- `hardware/`: target architecture and memory hierarchy.
- `ascendc/`: AscendC vector/API guidance that is not primarily about movement
  or synchronization.
- `memory/`: data movement, alignment, UB, queue, and buffering contracts.
- `synchronization/`: pipeline events, ordering, and visibility.
- `engineering/`: design, integration, validation, communication, and
  performance experience.

Knowledge records facts and bounded engineering rules. Procedures belong in
skills or workflows; implementation-specific teaching belongs in cases.
